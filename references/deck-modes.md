# 网页 Deck 的编辑与 SVG 预览

适用于已有可视化编辑版本及 SVG 确认稿的网页演示文档。先从实际项目、版本历史或用户提供的文件定位两个版本；截图只作为外观参考，不把截图当作可编辑源码。旧版缺失时说明缺口，不声称已经恢复。

## 两种模式

深色预览侧栏可复用 `assets/preview-scrollbars.css`：使用细灰绿滑块与深色轨道，悬停和键盘聚焦时提亮；保留原生滚动、拖动与键盘操作，不用隐藏滚动条替代样式优化。

- **编辑模式**：在完整 PPTedit 工作台内提供文字、元素、图层、布局、撤销与保存能力，默认使用已确认的新框架，见 [ppt-workspace-default.md](ppt-workspace-default.md)。编辑与预览共享真实文档源；旧版界面可作兼容入口，不作为默认交付。
- **预览模式**：沿用已确认的 SVG 查看界面。保留章节导航、居中按比例显示的画布、总览、讲述备注、全屏、页码、翻页与复制 SVG 等已有功能；隐藏编辑选框、控制点和属性面板。配色与版式沿用项目，不把某次截图的主题强加到其他 Deck。
- 提供清晰可见的「编辑 / 预览」切换控件，并标明当前模式。普通查看入口默认预览；显式编辑入口仍进入编辑。编辑器内部已有的「选择 / 预览」快捷切换不能冒充此处的 SVG 预览，除非确实接入同一渲染流程。

## 切换和内容一致性

- 两种模式共享文档源，以稳定的页面标识同步当前页；切换后停留在同一页，备注、页序和页数保持一致。
- 进入预览前提交当前文字输入，并从最新编辑状态生成或更新 SVG。预览生成不等于写盘成功；不通过刷新或加载旧导出文件丢弃未保存修改。
- 返回编辑时保留未保存内容和撤销历史。若采用不同页面入口，先实现可靠的状态传递与恢复，不能只互加链接造成内容丢失。
- SVG 更新失败时保留编辑内容，明确提示预览尚未更新，并允许返回编辑或重试；不能把旧 SVG 显示成最新结果。
- 预览中方向键用于翻页；编辑中输入框和文字编辑优先，已选元素可使用方向键微移。模式切换应释放另一模式的事件处理，避免一次按键触发两个动作。
- 切换本身不修改文档内容，不另存两份需要人工维护的文稿。复制或下载的 SVG 应与当前预览页一致。
- 备注展开时使用由视口决定的固定高度，不随各页文案长度变化而挤压画布或移动翻页栏；长备注在区域内独立滚动。备注获得焦点后支持键盘滚动，避免触发全局翻页；切换页面时备注滚回开头。保留原有备注显隐入口。

## 页序与显示页码

- 页面 ID 仅用于文件、讲稿和路由关联；对用户显示的页码必须取当前编排位置加一。
- 每次重排、增删页和保存后，统一刷新缩略图、大纲章节范围、总览、当前计数、编辑器和总页数；SVG 角标及复制结果使用同一顺序。
- 验收须覆盖非连续 ID（例如 09、06、08）、删除中间页、刷新恢复，检查显示始终为 01 至 N，并确认讲稿仍跟随原页面。
- 预览通过 `assets/preview-page-numbers.js` 同步显示和 SVG 页码，在宿主及导航脚本之后加载；复制 SVG 时调用 `PPT_NARRATION_HOST.normalizeSvg(text, pageId)`。

## 实施后的验收

封面使用现有视频时，可使用 `assets/cover-video.js` 叠加于 SVG 的对应画布区域；视频默认静音循环，遵循减少动效偏好，离页、总览、隐藏标签页或播放讲稿时暂停。保留手动暂停入口与静态 SVG 回退图。视频仅在 HTML 预览播放，不声称 SVG 本身包含可播放视频；选择真实项目素材，沿用 design.md 配色和已认可版式。

1. 在某一非首页修改文字及元素位置，切换到 SVG 预览，检查同页内容、布局和备注是否同步。
2. 返回编辑，确认修改仍在、撤销可用；连续切换不会重复绑定快捷键或重置页码。
3. 检查预览中的导航、总览、备注显隐、全屏、翻页和复制 SVG；确认不出现编辑覆盖层。
4. 检查显式编辑入口与默认预览入口；有保存能力时保存并刷新，确认两个模式读取同一更新后的文档。
5. 模拟预览生成失败，确认编辑草稿仍可继续使用，旧预览有明确状态提示。
6. 从后面的页面连续按上方向键回到第一页，确认侧栏滚动到真正的顶部，文档标题和开场章节完整可见；不能只保证第一页目录项可见。再次按上键保持回顶状态，中间页仍按需跟随当前目录项。

这些是后续实现 Deck 的要求。仅更新 skill 文档时，不声称已经修改或验收了实际页面。
