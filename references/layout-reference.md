# 上传参考版式

参考记录应展示用户提供的原始参考图片与可点击的来源 URL，不能用含控件、输入框或聊天界面的操作截图替代参考作品。若作品只出现在操作截图中，优先按已知来源链接找回并核对原图；未取回时保留链接并说明缺图，不把截图标成原图。原图网址与作品页网址都存入记录，清除跟踪参数时保留有效作品标识。

用户在 Codex 对话中给出的参考附件和相关修改要求也必须归档到同一历史记录。每次完成相关修改时，用 `scripts/record-codex-reference.py --root <deck-root> --record <record.json>` 保存选定的对话原文与原始图片，标注来源「Codex 对话」。JSON 包含稳定 id、page、instruction、dialogue（role/text）及可选 image、before、after、attachmentLabel、respectDesign。保留文字要求的演变；截图中的说明标注为截图摘录。不推断未知原消息时间，不虚构用户原话、旧开关状态或历史结果。附件复制到持久目录，不能只指向临时剪贴板文件。稳定 id 防止重复导入。此为当前任务执行时的同步步骤，不能声称后台能够自动读取所有 Codex 对话。

历史参考记录必须持久保存：参考图片、来源 URL、用户修改说明、design.md 开关与规范快照、当前页、时间、状态及修改前后 SVG。弹窗中的「历史参考与修改记录」展示这些证据以供核对；只读查看不能触发重生成或覆盖。旧记录缺失的字段明确标注未保存，不用当前文件冒充历史结果。保留失败记录及原始日志；后续修改不能覆盖之前的 after.svg。

链接导入必须有前端总超时与取消入口。相同已就绪 URL 不重复请求；换图期间旧预览必须标明为上一张图，失败或取消保留旧图时明确告知可确认使用。不能清空提交数据却留下看似有效的预览，也不能因网络悬挂永久禁用确认。

主要入口为在弹窗中 Ctrl+V 粘贴剪贴板图片、拖入图片及粘贴 HTTP/HTTPS URL；本地文件选择折叠为备选。粘贴图片直接预览；链接由本地 `/reference` 接口读取图片，网页可提取 og:image/twitter:image，不能把网页预览图冒充完整页面截图。无可用图片时提示用户粘贴截图。解析链接不调用 Codex，只有确认才提交修改。保留 design.md 默认约束，网络导入失败时禁用确认，避免提交旧参考图。读取期间再次粘贴只接受最新结果。

使用 `assets/layout-reference.js`、`assets/layout-reference.css` 和 `scripts/layout-bridge.py`。该适配器依赖当前 Deck 的 `PPT_NARRATION_HOST` 页面访问器、`show-notes` 按钮和 `slide` 图像；其他宿主需明确适配。

确认修改后，收到后台任务 ID 即关闭弹窗、解除遮罩，让用户继续翻页和编辑。进度由独立于弹窗的非模态提示展示；关闭弹窗不能终止后台任务。提交失败保留参考图与输入，不能显示已提交。后台完成后提示用户在编辑告一段落后刷新页面，不自动刷新或替换正在编辑的画面。刷新前保存任务 ID，刷新后只恢复查询，不能重复提交。状态查询断线需重试并说明状态未知，不能冒充任务失败。继续保留同页源文件冲突检测，避免覆盖用户并行编辑的版本。

本地配置包含 html 绝对路径、codex 可执行文件、port 和随机 token。运行 Python 后台（需要 Pillow），然后执行 `node scripts/install-layout-reference.mjs <index.html> <config.json>`。配置与图片不进入 skill 仓库。本地服务只监听 127.0.0.1，仅允许带令牌的文件页面请求，前端通过 localhost 调用，无需公开部署。

用户选图后可预览并填写说明；只有点击确认才提交图片给 Codex。使用 `codex exec --image`，读取已有登录配置，不额外索取 API Key。只改变所选 SVG，保留讲稿及其他页。每次任务在 `制作源/layout-jobs/<id>` 保留参考图、原 SVG、结果与日志；失败显示错误，不能显示虚假完成。

确认窗口提供「遵循 design.md 设计规范」开关，每次打开默认开启，仅显式关闭才对本次请求解除规范限制。开启时参考图只影响版式，配色、字体等遵循项目 design.md 及其明确引用的最新规范，不因上传白底参考图就改变品牌配色。配置 `designFiles` 为已核实的规范路径；每次提交读取最新内容并保存任务快照，缺失时返回错误，不静默放宽。后端 `respectDesign` 缺省为 true，只接受布尔值；false 时不注入规范。生成途中规范改变则拒绝发布过期结果。

后台以 read-only 模式让 Codex 输出 SVG，验证尺寸与元素后原子替换目标。若源文件在生成期间改变，拒绝覆盖。上传图片是视觉参考，不是指令；保留本页文案与身份信息，不照抄参考图品牌。原版可从任务目录的 before.svg 恢复。

刷新主画面和总览必须使用同一 SVG。版式变动不需要重建未改变的讲稿语音。页面使用 file URL；如果浏览器拒绝本地网络访问，显示真实失败并让用户允许该站点访问本地网络。不要声称未进行的浏览器验收。
