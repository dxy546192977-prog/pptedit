# 浏览器可视化编辑器接入

只在用户要求可视化编辑，或目标项目已接入本编辑器时使用这份参考。精确的批量修改仍应优先直接编辑源码；浏览器工作台更适合人工微调、探索和验收。

## 加载方式

在目标页面的 `</body>` 前加入：

```html
<script src="/h5-editor/bootstrap.js"></script>
```

`bootstrap.js` 会根据自身实际 URL 加载同目录的 `editor.js` 和 `editor.css`，因此资源可以放在站点子路径。保存接口也位于子路径时，使用同源地址显式配置：

```html
<script
  src="/your-base/h5-editor/bootstrap.js"
  data-h5ve-save-endpoint="/your-base/api/h5-editor/save/"
></script>
```

`bootstrap.js` 只应在以下情况加载编辑器主体：

- URL 以 `/edit` 结尾；
- URL 带有兼容参数 `?edit=1`。

推荐直接使用 `{page-url}?edit=1`。如果页面通过相对路径加载 CSS、脚本或图片，服务器把 `/edit` 静默 rewrite 到原 HTML 会改变浏览器的相对 URL 基准并导致资源失效。通用 Next.js 辅助器因此只为显式的 `.html/edit` 添加临时 redirect，兼容有无尾斜杠，最终地址为原 `.html?edit=1`。目录型页面必须由宿主为确定路径添加同类 redirect，不得使用全局 `/:path*/edit` 规则，以免拦截应用本身的编辑页。Next.js `output: "export"` 不支持自定义 redirects，辅助器会保持该配置不变，此时必须使用查询参数。只有页面已声明正确 `<base>` 或全部资源使用绝对 URL 时，宿主才可自行保留 `/edit` 地址。

标准资源位于：

```text
assets/h5-editor/
├── bootstrap.js
├── editor.js
└── editor.css
```

对具有 `public/` 目录的项目，先运行安装器的 `--check`，再决定是否 `--apply`。不要手工复制一部分资源，以免三个文件版本不一致。

## 内容根节点

编辑器依次选择明确画布容器、`main` 和 `body`。编辑器 UI 必须挂载在内容画布之外，并使用独立命名前缀，例如 `h5ve-`，避免污染页面样式。

普通 H5 不需要特定 DOM 结构。固定尺寸 Deck 建议明确声明设计坐标：

```html
<main id="stage" data-h5ve-width="1600" data-h5ve-height="900">
  <div id="deck">
    <section class="slide">...</section>
  </div>
</main>
```

- `#stage` 的显式尺寸优先于视口推断。
- `#deck > .slide` 表示可管理的幻灯片。
- 可选的 `[data-h5ve-slide-nav]` 会由编辑器同步幻灯片导航；普通 `#nav` 不会被接管。
- `[data-h5ve-page-number]` 标记可自动更新的页码，初始内容格式不限；`[data-h5ve-speaker-note]` 标记演讲者备注；`[data-h5ve-live-status]` 接收可访问性翻页状态。
- `[data-h5ve-structural]` 可把宿主装饰节点排除在图层操作之外；普通 `.chrome`、`.foot` 等类名没有特殊含义。
- 页面可实现 `window.__pptGoSlide(index)` 或 `window.__pptSyncDeckTransform(index)` 作为翻页桥接。
- 如果没有桥接函数，应按实际单页宽度移动 Deck，不假定固定像素宽度。
- 普通预览应保留方向键、页码、触摸滑动和原有媒体状态。

## 预览与选择模式

- 预览模式把方向键交给页面翻页。
- 选择模式在有选中元素时把方向键用于微移。
- 文字编辑、输入框、命令面板和其他浮层交互优先于翻页与元素移动。
- 退出编辑模式后，普通 URL 的外观、键盘操作和性能不应改变。

## 文字与元素选择

- 首次单击文字框只选中，保留拖拽和缩放能力。
- 已选中文字再次单击、双击或按 Enter / F2 进入就地编辑。
- 编辑文字时，方向键、Enter 和文本选择由原生编辑行为处理。
- 退出文字编辑后恢复元素原有的 `contenteditable` 状态。
- 拖框选择应在松手后保留结果；Shift 用于追加选择。
- 线条可放大命中区域，但不得改变视觉粗细或写入导出文件。

## 图层与几何约束

- 元素列表与画布选区、当前幻灯片、撤销与结构变化双向同步。
- 重命名、隐藏、锁定、删除、层级调整和重挂载都应进入撤销与保存链路。
- 锁定元素可以在元素列表中选中并解锁，但不能在画布中移动、缩放、改字或删除。
- 编组、解组和重挂载前记录屏幕矩形，DOM 关系变化后再按新的 `offsetParent` 重新锚定。
- 不得通过改变父容器定位方式来补偿编组或解组，以免影响其他绝对定位元素。

## 布局与尺寸

- 框架容器可支持自由、横向、纵向和网格流向，以及间距、内边距、外边距和裁剪。
- 宽度可区分固定、适应内容和填充父级；高度可区分固定和适应内容。
- 文字在适应或填充宽度时恢复自动高度，确保换行不裁字。
- 从自动尺寸切回固定尺寸，或手动缩放时，以当前视觉尺寸作为新固定值，不移动左上角。
- 填充网格容器的元素需在响应式列数变化时重新限制起始列，避免产生隐式列。

## 保存接口与安全

写盘是宿主选配能力。如果宿主实现 `/api/h5-editor/save/`，约定为：

- `GET ?path=<page>` 返回当前 `revision`；
- `POST` 接收 JSON `{ path, html, revision }`，保存成功后返回新 `revision`；
- 修订不一致时返回冲突，不静默覆盖磁盘版本。

安全要求：

- 只在本地开发环境和本机请求中开放；
- 只允许明确白名单中的 `.html` 文件；
- 规范化路径并拒绝 `..`、符号链接越界和非预期扩展名；
- 不允许根据浏览器传入路径写入任意文件；
- 不把凭据或 shell 参数传入前端。

没有保存接口时，工作台应保持只读或在保存失败时保留本地草稿，并允许下载 HTML。恢复草稿包含完整序列化页面并保存在当前 origin 的 `localStorage`；敏感页面不要使用共享开发域，恢复完成后应在版本历史中丢弃草稿或清除该站点数据。

## 序列化与导出

序列化或导出前移除：

- 编辑器根节点、选框、控制点、面板和提示层；
- 动态注入的 `editor.js`、`editor.css` 与编辑器 UI；
- 临时 `contenteditable`、选中标记、缩放和变换样式；
- 已识别的浏览器工具注入节点。

保留页面原有的脚本、导航、动效和内容结构。

页面显式接入的 `bootstrap.js` 会作为可再次进入编辑模式的入口保留在写回 HTML 中，它在普通 URL 下不会加载编辑器主体。需要完全脱离 PPTedit 的最终交付文件时，由宿主发布流程显式移除这一个接入脚本。

导出 SVG 时：

- 文字使用 `<text>` / `<tspan>`，基础图形使用对应矢量节点；
- 不使用 `<foreignObject>` 包裹整页 HTML；
- 图片和视频当前帧作为独立 `<image>` 图层，并使用可离线的 data URL；
- 不得将整页截图放入单个 `<image>` 伪装成矢量文件；
- 复杂滤镜、伪元素、网页动效和视频需要保留静态结果或明确降级。

导出 PNG 时使用真实画布尺寸，并在剪贴板权限不可用时降级为文件下载。

## 验收清单

- 普通 URL 不加载编辑器主体，`?edit=1` 和宿主提供的 `/edit` 入口可以进入编辑模式。
- 单击选中、文字就地编辑、拖拽、缩放、多选、撤销和翻页正常。
- 预览和选择模式的键盘优先级不冲突。
- 图层重命名、锁定、显隐、层级调整和结构变更后几何位置不变。
- 有保存接口时，刷新后结果仍存在；无保存接口时，可下载干净文件。
- 导出 HTML 不含编辑器残留；SVG 保留可编辑文字和矢量节点。
- 退出编辑模式后，普通预览的外观、交互和资源加载正常。
